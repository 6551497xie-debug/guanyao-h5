# XINMAI 1.0 — First-principles participation-loop audit

## Product verdict before this cut

The journey is technically complete but experientially inverted. The product spends most of its attention explaining what it will not do, how its internal evidence works, and why a screen is safe. The user is asked to observe the system rather than participate in a consequential experiment.

The previous success criterion — “a feedback item worth preserving” — is rejected. A saved item is not intrinsically valuable. The product earns another visit only when it helps the user make a better next move in a real situation.

## The user job

> Bring in one situation that is currently difficult, expose the automatic response it triggers, choose a small alternative, test it in reality, and return to update the next decision.

The product loop is therefore:

`REAL SITUATION → AUTOMATIC RESPONSE PATH → TESTABLE ALTERNATIVE → REALITY RESULT → MODEL UPDATE`

## Primary failures found

1. Birth and Genesis open with system explanations before giving the user a reason to participate.
2. Reality selection is the first screen with a concrete task, but it arrives after a long atmospheric prelude.
3. Six dimensions are presented as six separate observations with repeated select/confirm/save mechanics. This behaves like a questionnaire even when the questions differ.
4. Explanatory, protective and implementation-boundary copy competes with every primary action.
5. The response map describes the six answers but does not make the causal path immediately legible.
6. The product chooses one micro-action for the user and then explains why it is safe. The user does not experience a meaningful decision.
7. Return asks the user to create a record. It should instead ask what reality changed in the original prediction.
8. Crystal/trace language makes the end feel like artifact production. The real value is an updated working hypothesis for the next encounter.

## Frozen 1.0 participation model

### Act 1 — Signal

Body and emotion answer: `What fired first?`

### Act 2 — Prediction

Thought and action impulse answer: `What did the system predict and prepare to do?`

### Act 3 — Pattern and stake

Memory and protected need answer: `What familiar pattern was activated, and what was it trying not to lose?`

The six canonical selections remain distinct evidence, but the consumer presents one three-act construction rather than six unrelated pages.

## End-state value

The end of one loop must answer four concrete questions:

1. What situation triggered me?
2. What automatic path appeared?
3. What different move did I test?
4. What did reality teach me to keep, change or question next time?

No score, personality conclusion, mystical claim or collectible is needed.

## Cut order

1. Replace explanatory semantics with scene, choice and consequence language.
2. Remove repeated approach/save choreography and make six-dimensional participation a three-act path.
3. Reframe Response Map, Choice, Return and Ownership around prediction → experiment → result → update.
4. Refine hierarchy, spacing, contrast, progress and motion only after the loop is coherent.

Canonical Authority, six response IDs, receipts, Choice binding, Fact, Crystal, Body, repeated-cycle lifecycle and persisted topology remain unchanged.
