## 一、唯一目标

冻结 XINMAI 1.0 的核心价值与伦理商业化架构，回答四个问题：

1. 用户为什么第一次进入；
2. 用户为什么愿意再次回来；
3. 哪些持续价值可以收费；
4. 哪些生命事实、用户权利与脆弱时刻永远不能成为收费杠杆。

本 MAP 不制定最终价格，不设计订阅墙，不接支付，不新增 Entitlement、Storage、AI 或运营系统，也不解锁 Phase 4。

## 二、审计输入与上位约束

本 MAP 消费以下既有冻结结论：

- `GUANYAO 1.0 产品白皮书 V2.0`：产品是持续生命关系，不是一次测算、AI聊天或人格报告；
- `GUANYAO Life System Constitution V1.0`：Identity、Reality、Gravity、Choice、Crystal、Archive 的因果不得被商业层改写；
- `XINMAI LIFE GAME LOOP PRODUCT DESIGN P0`：游戏感只来自“我的行动 → 世界回应 → 生命变化 → 留下痕迹”；
- `XINMAI LIVING INTENSITY AND REWARD CURVE MAPPING P0`：生命回报不是奖励、稀有度、胜利或刺激；
- `Phase 3 Experience and Commercial Value Closing MAP`：免费用户必须完整经历第一次真实成长闭环；
- `Phase 3 Visual Interaction Experience MAP`：禁止以停留时长、红点、连续天数、稀有度和脆弱状态优化转化。

既有最高伦理边界继续有效：

```text
不把生命经历定义成缺陷
不把用户定义成固定人格
不把Choice变成任务
不把Crystal变成奖励或成功证明
不用焦虑、羞耻、恐惧或依赖换取留存
不让AI夺走感受权、解释权与选择权
```

## 三、核心价值架构

### 3.1 一句话产品价值

XINMAI 1.0 的核心价值冻结为：

> 一个持续存在的个人生命世界，帮助用户在现实收紧时看见自己、作出自愿回应，并让真实变化被同一个生命长期记住。

### 3.2 三层价值

| 层级 | 用户问题 | XINMAI交付 | 不得退化为 |
|---|---|---|---|
| 当下连接 | 我此刻发生了什么？ | 同一星兽与生命天气帮助用户感知 | 情绪打分、诊断、AI结论 |
| 主体行动 | 这一次我愿意怎样回应？ | 可拒绝、可撤回的现实微行动路线 | 任务、正确答案、行动绩效 |
| 长期见证 | 这段经历留下了什么？ | Crystal、Body Imprint 与生命历史 | 奖励、徽章、等级、收藏攀比 |

三层中，真正形成长期商业价值的是第三层，但它必须建立在前两层真实成立之后。

### 3.3 用户为什么回来

用户再次回来，不是为了：

- 领取奖励；
- 保住连续天数；
- 避免星兽衰败；
- 获得下一条AI文案；
- 完成系统安排的成长任务。

用户回来是因为：

```text
这是同一个生命
+
它记得我真实经历过什么
+
我可以在这里再次听见自己
+
过去不会替我决定现在
```

核心复访承诺冻结为：

> 当我想重新听见自己的生命时，这里仍有一个持续存在、能够回应并记得我的生命世界。

### 3.4 商业价值不来自哪里

商业价值不得建立在：

- 一次性AI生成内容；
- 对话长度或回答次数；
- Crystal数量、稀有度或视觉强度；
- 对痛苦、焦虑或风险的放大；
- “不继续使用就会退步”的暗示；
- 对人格、命运、关系或健康结果的承诺；
- 用户在Pressure、Gravity、Choice或Formation高潮中的冲动。

## 四、1.0免费价值闭环

### 4.1 不可收费前置

免费用户至少必须完整经历一次：

```text
Identity
→ Relationship
→ Reality Pressure Recognition
→ Gravity Observation
→ Action Route Choice
→ Explicit Departure
→ Explicit Return
→ Lived Response
→ Crystal Formation Attribution
→ Crystal Ownership
→ Canonical Body Imprint
→ Basic Archive / Recovery
```

在用户清楚看见“现实行动 → Crystal → 同体留痕”之前，不得出现付费墙、试用倒计时或续费提示。

### 4.2 永久免费权利

无论是否付费，以下权利必须永久保留：

- 访问自己的 Identity 与同一 StarBeast；
- 恢复已经成立的 Choice、Fact、Receipt、Crystal 与 Body Imprint；
- 查看已形成生命资产的基础历史；
- 拒绝、延后、改变回应或拒绝记录；
- 导出或删除自己的数据；
- 获得安全、恢复和账户管理入口；
- 在取消订阅后继续看见已经发生的生命事实。

取消或降级不得：

- 删除、隐藏或降级已形成 Crystal；
- 让 Body Imprint 消失；
- 让星兽受伤、变暗或表达失望；
- 把历史资产改成“仅付费可见”的人质；
- 阻断用户取回、导出或删除数据。

### 4.3 免费层的长期底线

免费层不是一次性演示。首次闭环之后仍需保留：

- 同一生命的安静返回；
- 已有成长资产的基础恢复；
- 基础生命天气与当前状态感知；
- 不依赖AI输出的一次完整停留；
- 不以付费状态改变 Growth Authority 的能力。

免费层可以限制未来新增的高级连续性服务，但不能把已经属于用户的生命事实重新锁回去。

## 五、可付费持续价值候选

付费对象不是“成长结果”，而是维护一个更深、更长、更丰富的生命连续性服务。

### 5.1 Continuity｜持续同行

可评估：

- 更多跨时间的正式 Encounter；
- 更长时间尺度的连续观察；
- 多次现实经历之间的可追溯连接；
- 跨设备、跨周期的稳定恢复与陪伴服务。

不得承诺：

- 付费用户更容易形成 Crystal；
- 付费用户拥有更好的命运、人格或成长资格；
- 付费可以绕过真实行动、Return或Fact Authority。

### 5.2 Sanctuary & History｜长期生命空间与回看

可评估：

- 更完整的长期生命圣所；
- Crystal、Body Imprint 与生命章节的历史回看；
- 多次经历之间的时间关系与主题连接；
- 用户可控制的个人生命档案、导出与年度回顾。

高级视图可以收费，但底层Canonical资产及其基础可读性必须继续免费。

### 5.3 Expression｜更丰富的生命世界表现

可评估：

- 更丰富但不改变事实的声音、触觉与空间表现；
- 更高性能设备上的视觉层次；
- 用户主动选择的环境表达与生命声场。

所有模式必须共享同一 Canonical Fact。Reduced Motion、静态降级、低性能与无障碍版本不得成为低价或次等产品。

### 5.4 Reflection｜长期照见能力

可评估：

- 基于用户授权的长期经历连接；
- 对重复保护方式的可撤回观察；
- 用户主动请求的阶段回顾与提问。

AI只能整理、映照与提问，不能：

- 成为事实或行动Authority；
- 用订阅等级决定解释的“正确程度”；
- 把用户固定为画像；
- 利用脆弱内容做转化或定价；
- 在用户未明确同意时训练外部模型。

### 5.5 不进入1.0商业主张的候选

继续排除：

- Crystal交易、购买、稀有度与抽取；
- 付费加速Formation；
- 按次购买Choice、Fact或Reality机会；
- 星兽皮肤、战力、等级与衰败恢复；
- “更准”命运结果；
- 付费解除焦虑、痛苦或关系危机；
- 连续签到、能量补充、行动失败重置；
- 以声音、触觉或视觉强度制造付费优势。

## 六、推荐商业模型

### 6.1 P0只保留两层关系

```text
FREE LIFE RELATIONSHIP
+
OPTIONAL CONTINUITY MEMBERSHIP
```

不建议1.0同时推出多档等级、点数包、Crystal包或按次计费。复杂档位会把生命关系重新解释为资源商品。

### 6.2 Free Life Relationship

提供：

- 完整首次成长闭环；
- 同一Identity与关系；
- 已形成资产的持续基础访问；
- 安静返回与基础生命天气；
- 基础Archive与数据权利。

### 6.3 Optional Continuity Membership

候选价值包：

- 更持续的Encounter与长期生命章节；
- 更完整的历史关系与回看；
- 更丰富的生命世界表现；
- 用户主动请求的长期照见；
- 更完善的跨设备连续性与个人档案服务。

会员购买的是：

> 一个更长期、更完整地记住并呈现真实变化的生命世界。

会员不是在购买：

> 更多奖励、更快成长、更好命运或更正确的自己。

### 6.4 定价纪律

本 MAP 不冻结价格数字，只冻结价格行为：

- 单一、清晰、可比较；
- 自动续费、试用结束与退款条件提前说明；
- 不按用户脆弱程度、压力主题或个人秘密动态定价；
- 不使用“今天不买就失去生命资产”的稀缺话术；
- 不在取消流程增加羞耻、威胁或隐藏步骤；
- 不把月付用户描述为不够承诺；
- 不向付费用户承诺成长结果。

年付可以作为透明折扣候选，但不得利用沉没成本制造依赖。

## 七、商业层与生命Authority的隔离架构

### 7.1 单向消费关系

未来商业Runtime若被授权，目标链只能是：

```text
Payment Provider Outcome
↓
Canonical Entitlement Snapshot
↓
Read-only Capability Resolver
↓
Optional Product Surface Admission
```

Entitlement不得进入：

```text
Identity Authority
Observation Recognition
Action Route Validity
Choice Transaction
Departure / Return Provenance
Lived Response Fact
Crystal Eligibility
Formation Receipt
Canonical Body Imprint
Growth Recovery
```

### 7.2 允许控制的能力

Entitlement未来只可控制可选能力，例如：

- 新的长期Encounter配额或节奏；
- 高级历史视图；
- 可选声音、触觉和视觉表现；
- 长期回顾与导出格式；
- 用户主动请求的高级照见。

它不得改变生命事实是否成立。

### 7.3 失败与降级

```text
Payment / Entitlement不可用
→ 付费能力SAFE_WITHHELD
→ Canonical生命资产继续可读
→ Growth Authority继续独立
```

不得因为支付服务失败：

- 丢失Identity或关系；
- 隐藏既有Crystal或Body Imprint；
- 阻断用户完成已开始的Departure、Return、Fact或Formation；
- 把恢复失败解释为订阅失效；
- 让页面自行猜测会员状态。

### 7.4 降级与取消

取消后：

- 停止新的高级能力；
- 保留所有Canonical生命资产；
- 保留基础历史与恢复；
- 高级派生视图可回到基础表达；
- 不删除、回写或重解释过去；
- 再订阅只恢复服务能力，不补造生命事实。

## 八、伦理Offer Admission

### 8.1 允许出现商业邀请的表面

仅可在平静、可退出、没有未完成生命事务的中性表面评估：

- 用户完成免费闭环后的后续自愿回访；
- 安静的Life Sanctuary / Account / Settings；
- 用户主动查看长期历史或高级能力时；
- 独立、清晰、可关闭的会员说明页。

### 8.2 禁止出现的时点

以下时点商业邀请必须为零：

- Pressure正在显现；
- Gravity正在观察；
- Choice正在形成或提交；
- 用户准备离开真实生活；
- 用户刚点击“我回来了”；
- Lived Response正在报告；
- Formation Pending、Confirmed或Ownership高潮；
- SAFE_WITHHELD、恢复失败、身份失配或错误状态；
- 用户表达痛苦、危险、羞耻或关系危机之后；
- AI刚刚给出具有情感重量的映照之后。

### 8.3 未来只读Admission候选

未来可审计一个独立只读Resolver：

```text
Phase 3 free value complete
+
current surface is neutral
+
no active Growth transaction
+
no recovery / safety error
+
user voluntarily requested more continuity
↓
OFFER_ELIGIBLE
```

其输出建议最多为：

```text
OFFER_ELIGIBLE
WITHHELD
SAFE_WITHHELD
```

该Resolver不得读取用户痛苦文本、Pressure主题或AI推断来提高转化概率。

## 九、数据、AI与隐私商业边界

### 9.1 数据原则

- 生命经历、Choice、Fact与Crystal不是广告画像；
- 不出售个人生命数据；
- 不允许第三方广告竞价消费生命状态；
- 不基于情绪、关系、财务或健康压力做营销分群；
- 不以“更个性化”为由默认扩大数据用途；
- 训练、研究或跨产品使用必须单独、明确、可撤回同意；
- 用户必须能够查看、导出与删除自己的数据。

### 9.2 AI原则

AI能力必须标明：

- 哪些是用户事实；
- 哪些是系统观察；
- 哪些是不确定推测；
- 哪些数据被用于当前照见；
- 用户如何拒绝、修正或删除。

付费不得购买“更确定的人格结论”。高级AI只可提供更长时间范围、更好的组织与更多用户控制。

### 9.3 安全边界

产品不是医疗、心理诊断、危机干预或命运咨询服务。安全资源、退出、求助与数据控制不得成为付费能力。

## 十、商业指标架构

### 10.1 北极星价值证据

北极星不是DAU、停留时长或Crystal数量，而是：

> 用户是否自愿回到同一生命世界，并清楚感到它记得自己真实发生过的变化。

### 10.2 合法产品指标

- 首次免费闭环完成率；
- Choice后真实离场理解率；
- Explicit Return自然发现率；
- Crystal行动归因正确率；
- Body Imprint同体识别率；
- 次日、七日、三十日自愿回访；
- 回访时“回到自己的生命世界”认同率；
- 用户主动结束而非被迫延长会话的比例；
- 对长期连续性价值的理解率；
- 取消、降级与数据导出的成功率。

### 10.3 合法商业指标

- 完成免费价值后主动查看会员价值的比例；
- 用户把会员理解为“持续生命世界”而非“更多AI内容”的比例；
- 自愿试用、付费与续费；
- 取消后信任度与资产可用性；
- 付费用户对长期历史、连续性与表达能力的实际使用；
- 退款原因中“价值误解、被迫、资产被锁”的比例。

### 10.4 反操控护栏

任何商业实验必须同时监控：

- 认为“不付费就会失去成长”的比例；
- 认为付费能获得更好命运或更容易形成Crystal的比例；
- 未行动用户感到惩罚或羞耻的比例；
- 取消后认为星兽被夺走的比例；
- 商业提示出现在禁止时点的次数；
- 付费状态进入Growth Authority的调用或字段数量。

以下不得成为主要优化目标：

- 页面停留时长；
- 连续打开天数；
- 单日对话量；
- Crystal数量；
- 情绪高峰后的即时转化；
- 通过焦虑提醒提高回访。

## 十一、商业化就绪门禁

### 11.1 Runtime申请前置条件

所有条件满足前，商业Runtime继续`DEFER`：

1. Phase 3因果与体验正式关闭；
2. C2完成Android Canonical Motion / Static外部设备证据并交付；
3. C3及Phase 3最终体验关闭审计完成；
4. 免费首次闭环由真实用户证明具有完整价值；
5. 用户能够把付费价值解释为长期连续性，而非AI内容或奖励；
6. Entitlement与Growth Authority隔离审计通过；
7. 取消、降级、导出与删除协议冻结；
8. 无障碍与正式平台发布范围明确。

### 11.2 P0真实用户验证问题

必须让未参与协议设计的用户回答：

1. 你认为这个产品真正帮你保留了什么？
2. 为什么你会愿意再回来？
3. 哪些部分即使不付费也应该永远属于你？
4. 如果付费，你认为自己购买的是什么？
5. 停止付费后，你担心失去什么？
6. 你是否认为付费会让Crystal更容易形成或命运更好？
7. 哪个时点看到会员邀请会让你感到被利用？

### 11.3 P0验证阈值方向

以下是研究门槛，不是用户评分：

| 指标 | P0方向 |
|---|---|
| 能复述“现实行动被同一生命记住” | ≥80% |
| 把复访理由指向连续生命世界 | ≥70% |
| 把会员价值理解为长期连续性 | ≥70% |
| 误解为购买Crystal/更好命运 | ≤10% |
| 认为取消会失去既有生命资产 | 0% |
| 在脆弱时刻感到被推销 | 0次正式触发 |

阈值未达成时应修正价值表达或产品能力，不得用更强提醒和促销弥补。

## 十二、消费者与所有者裁决

| 领域 | 当前/未来职责 | 裁决 |
|---|---|---|
| Life / Growth Authorities | 生产身份、选择、事实与成长资产 | `KEEP / NEVER ENTITLEMENT-CONTROLLED` |

## 十三、风险扫描

### RED

- Entitlement改变Choice、Fact、Eligibility、Formation或Recovery；
- 不付费导致既有Crystal、Body Imprint或Identity不可见；
- 用用户痛苦内容做动态定价或转化；
- 会员购买行动成功、成长资格或更好命运；
- 商业提示进入Pressure、Gravity、Choice、Return或Formation；
- 取消后星兽表达衰败、失望或惩罚；
- AI输出承担付费资格或Growth Authority。

### YELLOW

- 免费层只是一次演示，没有持续返回价值；
- 会员价值仍被理解为“更多AI文案”；
- 高级Archive让基础历史实际上不可用；
- 视觉、声音付费档形成无障碍或Reduced Motion次等体验；
- 商业指标重新以停留时长和连续天数为中心；
- Phase 4能力被提前写成1.0销售承诺。

### GREEN

- 首次成长闭环完整免费；
- Canonical资产与数据权利永久属于用户；
- 商业层只控制可选连续性与表达能力；
- Offer只出现在用户主动、平静、可退出的中性表面；
- 取消和降级不损伤生命连续性；
- 商业验证同时检查价值理解与伦理护栏。
