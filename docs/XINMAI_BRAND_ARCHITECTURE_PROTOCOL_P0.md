# XINMAI BRAND ARCHITECTURE PROTOCOL P0

## 文档定位

- 项目：GUANYAO 1.0
- 品牌母体：XINMAI / 星脉之境
- 协议性质：品牌架构协议
- 协议阶段：P0
- 工程影响：无

本协议只冻结品牌承载关系，不修改代码，不修改现有 GUANYAO Runtime，不迁移变量，不改路由，不影响当前产品运行。

---

## 一、任务背景

当前产品已经形成以下文明资产：

- GUANYAO 1.0 产品白皮书 V2.0；
- Core Awakening Protocol；
- Dust · StarBeast · Crystal Extension；
- Life Engine 生命引擎体系；
- 星兽视觉宪法；
- 七星生命经络体系；
- AI 照见协议。

与此同时，“观爻 / GUANYAO”作为单一产品名称存在商标注册不确定性。

品牌承载方式因此从“单一产品名”升级为：

> 品牌宇宙 + 生命引擎系统。

这次升级不是废弃 GUANYAO，而是保护并扩大已经形成的产品文明资产。

---

## 二、品牌架构最高原则

冻结：

> 商标变化不能破坏已经形成的产品文明资产。

GUANYAO 不被替换、不被降级为历史名称，而是从单一产品名升级为底层生命系统名称。

任何未来品牌调整都必须满足：

1. 用户品牌可以演进；
2. GUANYAO 生命方法体系保持连续；
3. 既有 Runtime 与工程资产保持稳定；
4. 产品世界观、生命关系和长期资产不因商标变化而断裂。

## 十、工程迁移原则

当前继续保留：

- `guanyao-h5`；
- GUANYAO 代码命名；
- GUANYAO 协议文件；
- 既有类型、服务、Runtime 与路由。

原因：

> GUANYAO 已经成为生命系统资产，而不是需要被品牌替换的临时命名。

未来新增 Brand Layer 时，结构应为：

```text
XINMAI Brand
↓
GUANYAO Life Engine
↓
Existing Runtime
```

### 当前禁止

禁止立即全量替换：

- 文件名；
- 类型名；
- 路由名；
- 服务名；
- Runtime 名；
- 已冻结协议名称。

任何未来工程迁移都必须以增量品牌层消费为前提，不能通过全仓改名制造技术风险或产品语义断裂。
