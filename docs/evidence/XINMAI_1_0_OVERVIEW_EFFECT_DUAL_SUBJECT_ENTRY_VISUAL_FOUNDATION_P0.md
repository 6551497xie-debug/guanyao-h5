# XINMAI 1.0 · 总观效应双主体入口视觉基础证据 P0

## 裁决

首屏视觉基础完成，可进入正式验收。此次施工只建立宏观视域与交互锚点，不修改任何产品 Authority。

冻结世界观公理：**出生不是生命的开始，而是相遇的开始。** 宇宙里一直存在两个生命；出生时刻只负责让地球上的用户与星河中的它获得彼此寻找的坐标。

## 视觉关系

- 地球：现实、肉身与社会生活发生之处。
- 月球：制造观看距离，让用户暂时离开狭窄的自我视角。
- 太阳：不作为第三个中心物体陈列，只以屏外定向光建立空间秩序。
- 用户：第一人称观察者与行动者；不再绘制第二个替身或“生命核心”。
- 星兽：远方另一宇宙生命的独立呼吸信号，不是用户投影、宠物、守护者或命定解释；首屏不提前展示完整形体。
- 事实源：只有用户明确操作才能形成后续事实；视觉靠近与粒子响应不写入 Authority。

## 交互结果

- 首屏先呈现月地宏观视域与远方生命呼吸，再用“校准相遇坐标”把主体从宇宙尺度落回现实坐标。
- 用户靠近主操作时，地球出生锚点与星兽信号建立轻微响应，但不预演相遇结果。
- Motion 使用连续 2.5D 深空粒子与视差；Reduced Motion 与 Forward SAFE_WITHHELD 使用同一构图的静态等价画面。
- 画面、语义和操作共享“双主体、单事实源”公开边界。
