## 5. 语义 → 物理变化契约

| 语义阶段 | 必需 typed 事实 | NEAR / MID / FAR 只读变化 | 用户动作 | 明确禁止 |
| --- | --- | --- | --- | --- |
| Reality approaching | current Reality admission；Pressure 尚未 recognized | FAR 极慢保持；MID 同一身体；NEAR 现实候选在身体外围靠近但不命名 | 用户靠近/浏览候选 | 随机生成问题；靠近即写 Recognition |
| Pressure recognized | current Recognition Receipt 与 selected seed 一致 | 唯一现实节点从游移变为稳定；遮蔽结构显影；身体身份不变 | 用户明确“认出”后继续 | 动画稳定即确认；诊断、人格标签 |
| Gravity observing | current Gravity admission；Observation available | MID 局部收紧；NEAR 呈现重复牵引路径，保护、收益、代价尚未下结论 | 用户逐项观察 | 由亮度决定好坏；把压力当命运 |
| Gravity recognized | Observation recognized proof current | 原牵引路径变得可追溯；保护功能与代价同时可见，不遮蔽身体 | 用户明确确认观察 | 编造童年/创伤；视觉替用户确认 |
| Choice ready | `READY_TO_PRESENT` + validated Action Route | `CHOICE_ACTION` 成为唯一 NEAR；旧保护路径与候选新路径构成双向可比较力场 | 用户通过 native controls 选择 | “最佳选择”、奖励色、Renderer 直接提交 |
| Choice committed | committed intention / `RESUME_COMMITTED` lineage current | 选定方向收存为未结晶痕迹；世界向现实方向打开，但不形成 Crystal | 用户明确 Departure | 宣称行动完成、Fact/Eligibility/Formation |
| Safe withheld | 任一 refs / lifecycle / proof mismatch | Scene 不宣称语义物理化成功；保留可访问的真实恢复/重试控件 | 用户可安全返回/重试 | 通用星空或旧 DOM 假装已进入下一阶段 |

Choice 力场必须同时保留“保护”“收益”“代价”三类可见依据；Human agency 不得变成道德义务，系统不得将其中一侧塑造成胜利路线。

## 6. FAR / MID / NEAR 深度语法

| 层 | V3 责任 | 允许变化 | 不允许变化 |
| --- | --- | --- | --- |
| FAR | 连续现实环境尺度 | 极慢方向/密度变化；质量降级时先减少 | 随阶段重建通用星空；强 bloom；随机镜头晃动 |
| MID | 同一生命身体、经络、身份关系 | 局部遮蔽、收紧、开放、稳定 resonance；C2 Body Presenter 始终 1 | 第二身体、通用球体、闭合外轨、改写 Body/Imprint |
| NEAR | 当前唯一可理解/可触摸的 Reality、Observation 或 Choice 对象 | typed reference 驱动的唯一对象；native control 对应命中 | Canvas 全屏模糊点击；同时出现 Observation 与 Choice 两个成功对象 |

层间冻结规律：

- 尺度：FAR 最大、MID 稳定、NEAR 最明确；不得靠粒子数量制造前后。
- 清晰度：当前 NEAR 最清晰；MID 保持可辨；FAR 低频但不消失。
- 亮度：语义重要性不等于道德正确；Choice 两侧不使用“好/坏”色彩编码。
- 遮挡：NEAR 可局部遮挡 MID，但不得遮住 Body identity、关键状态或 native control。
- 速度：FAR 最慢、MID 低频、NEAR 仅在真实状态变化时响应。
- Reduced Motion：用尺度、遮挡、连接、对比和位置保持同一构图，不能只把速度设为 0。

## 9. 文字、控件与无障碍

- Reality、Observation、Choice 的责任动作继续使用可聚焦、可命名、真实命中的 native controls。
- 空间对象只解释当前 typed fact，不能替代 Recognition 或 Choice 确认。
- Canvas / decorative SVG 对辅助技术静默；Accessible Semantic Mirror 读取同一 projection 与既有 facts。
- live status 只在 Authority stage 真正变化时播报一次；refresh/recovery 不重播“已认出”或“已选择”。
- 阅读顺序：同一生命 → 当前 Reality/Observation → 保护/收益/代价 → 当前可做动作 → withheld/recovery。
- 320×568 至 430×932 保持单一纵向滚动责任；200% 下 native controls 可达，NEAR 不遮住操作。
- V3 不改业务文案；若现有文字无法满足语义理解，单列 Copy Gate，不在 Runtime 迁移中临场改写。
