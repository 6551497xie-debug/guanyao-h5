# 02｜分阶段知情同意模板

> 模板状态：`EMPTY / NOT A SIGNED CONSENT`

## A. 核心同意

参与者必须在Day 0前理解：

- 这是产品研究，不是治疗、诊断、医疗或命运咨询；
- 研究包含首次体验、1–3天现实窗口和后续回访；
- 现实行动完全自愿，可以改变、延后、不尝试或拒绝记录；
- 参加、退出、是否行动和购买意向不影响补偿；
- 当前不会发生购买，也不会建立付费账户；
- 可随时暂停、退出或要求删除允许删除的数据；
- 研究团队会区分用户事实、观察和研究者推断。

确认：`AGREE / DO NOT AGREE`

## B. 数据最小化同意

允许记录：

- 产品路径与关键交互结果；
- 无提示回答；
- 回访发生时间与是否收到研究提醒；
- A/B/C分层裁决；
- 设备与无障碍上下文；
- 最小必要的匿名研究笔记。

默认不记录：

- 完整人生故事；
- 医疗或心理诊断；
- 精确财务信息；
- 与研究无关的通讯录、位置或账户数据；
- 支付信息。

确认：`AGREE / DO NOT AGREE`

## D. 纵向回访同意

参与者理解：

- Day 1–3窗口不会用产品提醒催促回访；
- 如研究安排需要，中性研究提醒会单独标记；
- 研究提醒后的回访不会被报告为自然回访；
- 未回访不会受到惩罚，也不会影响补偿。

确认：`AGREE / DO NOT AGREE`

## E. 商业概念同意

只有完成前置体验后才询问：

> 你是否愿意在中性研究环节查看四种未来持续服务概念？不会显示价格，不会购买，不会锁定任何资产。

选择：`AGREE / SKIP`

选择`SKIP`时C层为`NOT SHOWN`，不能解释为不愿付费。

## F. 非交易意向与等待名单

等待名单或购买意向必须在C层结束后单独询问：

> 你是否愿意留下一个独立的、可撤回的未来通知意向？这不是购买、预订或优先权益。
