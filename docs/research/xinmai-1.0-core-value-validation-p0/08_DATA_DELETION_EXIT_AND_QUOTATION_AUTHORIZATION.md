# 08｜数据删除、退出与引用授权流程

> 模板状态：`PROCESS PREP / NO LIVE DATA SYSTEM`

## 1. 数据分类

| 数据 | 默认处理 |
|---|---|
| 参与者联系方式 | 与研究证据分离；当前阶段不得收集 |
| participantReference | 去标识研究引用 |
| 产品事件与路径结果 | 最小必要记录 |
| 原话 | 按引用授权范围保存 |
| 音频/视频 | 仅在单独同意后保存 |
| 敏感生命叙述 | 不主动收集；必要片段最小化 |
| 非交易意向 | 单独同意；不得写入产品生命资产 |

## 2. 退出入口

参与者可选择：

```text
PAUSE_CURRENT_SESSION
END_CURRENT_SESSION
WITHDRAW_FUTURE_CONTACT
WITHDRAW_FROM_STUDY
DELETE_IDENTIFIABLE_DATA
REVOKE_INTERNAL_QUOTE
REVOKE_EXTERNAL_QUOTE
```

主持人不得追问退出原因以挽留参与者。

## 3. 退出处理清单

| 步骤 | 完成 |
|---|---|
| 确认参与者选择 | `[ ]` |
| 停止录音/录像 | `[ ]` |
| 停止后续研究提醒 | `[ ]` |
| 标记补偿不受影响 | `[ ]` |
| 撤销未来联系 | `[ ]` |
| 根据请求删除明细 | `[ ]` |
| 删除或撤销原话引用 | `[ ]` |
| 完成删除复核 | `[ ]` |
| 向参与者确认完成 | `[ ]` |

## 4. 分母处理

- 已开始Day 0的退出者继续计入`N_ENROLLED`聚合人数，前提是同意或适用要求允许保留去标识聚合计数；
- 退出者不进入任何成功分子；
- 请求删除全部研究数据时删除明细和引用；
- 如无法合法保留聚合退出数，报告必须说明分母调整及原因，不能静默删除；
- 退出不得解释为不理解、不愿回访或不愿付费。

## 5. 引用授权

每条引用必须记录：

```text
quoteReference: [填写]
participantReference: [填写]
exactQuote: [填写]
context: [A / B / C]
authorization: [INTERNAL / EXTERNAL / NONE]
deidentified: [YES / NO]
revoked: [YES / NO]
```

不得为了故事完整性拼接不同参与者原话。

## 6. 保留期限

执行前必须由隐私与伦理审查冻结：

- 联系信息保留期限；
- 音视频保留期限；
- 去标识笔记保留期限；
- 删除响应时限；
- 备份删除方式；
- 访问权限与审计记录。

当前文档不自行设定法律保留期。

## 7. 等待名单隔离

未来如获授权建立等待名单：

- 需独立同意；
- 与研究补偿无关；
- 与生命资产和Growth Authority隔离；
- 可随时退出；
- 不得将未同意者自动加入；
- 当前工具包不得收集真实联系方式。
