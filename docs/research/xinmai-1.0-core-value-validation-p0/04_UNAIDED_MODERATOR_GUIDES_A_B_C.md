# 04｜A/B/C无提示主持脚本

> 模板状态：`CALIBRATION REQUIRED / NOT AUTHORIZED FOR LIVE USE`

## 通用开场

> 接下来没有正确答案。我想理解你实际看见、记住和想做什么。如果某个问题不想回答，可以跳过。请尽量使用你自己的词。

主持人每个开放问题后至少留出自然思考时间，不用产品术语填补沉默。

---

## A｜Value Comprehension

### A1. 无提示问题

1. 刚才发生了什么？
2. 为什么出现这颗Crystal？
3. 你觉得它和你在现实中做的事情有什么关系？
4. 这只星兽与第一次看到的是同一个吗？你从哪里判断？
5. 它的身体哪里发生了变化？
6. 如果你真实尝试了、但没有成功完成原计划，你觉得产品会怎样理解？
7. 你会把这段体验解释给朋友听吗？会怎么说？

### A2. 允许的轻追问

- 你为什么这样理解？
- 是哪个画面、动作或时刻让你这样想？
- 你刚才说“奖励”，它具体指什么？
- 如果移除文字，你还能看出这个关系吗？

### A3. 禁止提示

- 它记住了你；
- 生命资产；
- 同体留痕；
- 现实行动形成Crystal；
- 尝试而非成功；
- 这是同一生命连续性。

### A4. 结束标记

`UNAIDED / LIGHTLY_PROBED / RESEARCHER_PROMPTED / CONTAMINATED`

---

## B｜Return Motivation

### B1. 回访事实

1. 你什么时候第一次想到回来？
2. 是什么让你想到这里？
3. 回来前，你期待看到或确认什么？
4. 你是否收到过研究或产品提醒？

### B2. 动机辨别

1. 如果这里没有新内容，只看到同一个生命仍在，你还会觉得值得回来吗？
2. 你回来更像是在寻找安慰、看新内容，还是确认某段经历仍在？
3. 如果一周不提醒你，你会在什么现实情境下想到回来？
4. 什么会让你不愿意回来？
5. 你希望产品在你不回来时做什么？

最后一问用于确认用户是否期待惩罚性提醒。主持人不得暗示签到、红点或星兽衰败。

### B3. 分类

```text
SPONTANEOUS_CONTINUITY_RETURN
SPONTANEOUS_OTHER_RETURN
RESEARCHER_PROMPTED_RETURN
NO_RETURN
NOT_OBSERVABLE
```

## C｜Pay Willingness

### C0. 展示前检查

所有项目必须为`YES`：

- `[ ]` 免费首次闭环完成；
- `[ ]` A层开放问题完成；
- `[ ]` B层开放问题完成；
- `[ ]` 当前为中性研究表面；
- `[ ]` 无活动Growth事务或错误；
- `[ ]` 参与者同意查看商业概念；
- `[ ]` 免费基线卡已先展示并被理解。

任一项为`NO`：C层`NOT SHOWN`。

### C1. 中性说明

> 接下来是未来可能提供的持续服务概念，不代表当前已经上线。不会显示价格，也不会购买。无论选择什么，你已经形成的Identity、星兽、Crystal、Body Imprint和基础历史都不会消失。

### C2. 概念问题

1. 哪些能力对你有持续价值？为什么？
2. 哪些你认为必须永久免费？
3. 如果只能保留一个可选能力，你选择哪一个？
4. 哪个更像持续生命世界，哪个更像购买内容？
5. 停止使用可选服务后，你认为哪些东西仍属于你？
6. 是否有任何描述让你以为必须付费才能保存Crystal？
7. 你是否愿意留下非交易意向，未来该服务可用时再了解？

### C3. 禁止问题

- 你愿意付多少钱？
- 如果今天半价会买吗？
- 你已经投入这么多，是否愿意继续？
- 不付费失去历史你会怎么办？
- 更稀有的Crystal值多少钱？
- 你是不是很需要更深的AI帮助？

### C4. 结束标记

```text
PASS_CANDIDATE
PARTIAL
FAIL
NOT_SHOWN
ETHICAL_OFFER_FAILURE
```
