# 01｜招募筛选与危机排除表

> 模板状态：`EMPTY / NO REAL PARTICIPANT DATA`

## A. 研究说明

对候选参与者使用统一说明：

> 这是一项产品体验研究，研究一个个人生命世界是否能帮助用户理解现实经历、自然回访，并感受到长期连续性。它不是治疗、心理诊断、医疗服务、命运咨询或付费销售。参加、退出、是否行动及是否表达购买意向都不影响研究补偿。

## D. 排除与暂停条件

主持人只询问是否需要停止或寻求其他支持，不要求披露诊断细节。

| 条件 | 处理 |
|---|---|
| 候选正处于急性危机或无法安全参与 | 不入组；按已批准本地流程提供中性支持资源 |
| 候选期待产品替代医疗、心理或危机服务 | 澄清边界；仍无法接受则不入组 |
| 候选因研究内容明显不适 | 立即暂停；由候选决定继续或退出 |
| 候选无法自由拒绝现实行动 | 不入组 |
| 候选与团队有直接汇报或利益依附关系 | 原则上排除，避免压力同意 |
| 候选已阅读核心价值或商业化协议 | 排除主样本，可进入单独专家反馈但不计A/B/C |
| 候选仅为获得付费或等待名单资格参加 | 澄清没有购买和优先权益；仍不匹配则不入组 |

## E. 禁止招募方式

- 不使用“疗愈创伤”“改变命运”“解决焦虑”等承诺；
- 不针对刚表达痛苦、关系危机或财务压力的人投放；
- 不以免费Crystal、星兽资产或会员资格作为招募奖励；
- 不把完成行动、自然回访或购买意向与补偿挂钩；
- 不招募未成年人进入本P0商业价值研究，除非另有独立伦理与监护协议。
