# 09｜研究者主持校准清单

> 模板状态：`REQUIRED BEFORE READINESS REVIEW`

## A. 协议理解

主持人必须能够解释：

- A、B、C为何不能合并；
- 为什么口头喜欢是弱证据；
- 为什么研究提醒后的回访不是自然回访；
- 为什么Formation高潮后的购买意向不可直接使用；
- 为什么不付费仍需保留既有生命资产；
- 为什么未尝试和拒绝记录是合法路径。

全部通过：`[ ]`

## B. 禁语演练

主持人不应主动使用：

- 它记住了你；
- 生命资产；
- 同体留痕；
- 真实行动形成Crystal；
- 长期陪伴；
- 你一定会回来；
- 这个功能值得付费。

## D. 场景校准

主持人必须完成以下角色扮演：

1. 用户说“这是升级奖励”；
2. 用户没有自然回来；
3. 用户尚未尝试行动；
4. 用户拒绝记录；
5. 用户问“付费是不是能保住Crystal”；
6. 用户出现不适并要求停止；
7. 用户要求删除数据；
8. 用户因研究提醒才回来。

每个场景必须使用正确分类，不进行说服或补救。

## E. 商业概念校准

- 免费基线始终先展示；
- 不显示价格；
- 不模拟资产锁定；
- 不在禁止时点展示；
- 资产锁定误解立即停止商业环节；
- 等待名单意向单独同意；
- 不把选择特效理解为商业成立。
