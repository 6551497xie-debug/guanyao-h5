## 四、新用户首次完整成长

正式 Motion 浏览器重新完成：

```text
Launch
→ 生命坐标
→ 南方朱雀 · 星宿
→ “认出它一直在那里”
→ Life Whisper
→ Relationship Name：阿曜
→ /reality
→ Pressure Recognition
→ /dynamics
→ Gravity Observation
→ Action Route
→ Choice
→ Explicit Departure
→ Explicit Return
→ Changed Response
→ /reality
```

### 成立事实

- Identity 只出生一次；
- 同一星兽从 Genesis 延续到 Gravity；
- Whisper 由同一星兽关系链承接；
- 可选关系名成功保存；
- Pressure 候选、Observation、Action Route 与 Choice 均由正式路径产生；
- Departure 不提前创建新 Reality；
- Return 后才开放 Lived Response；
- Changed Response 被当作合法现实事实，不要求与原 Choice 完全一致；

- Fact 成立后没有出现用户可辨认的 Crystal Formation 时刻；
- 页面没有说明“这颗 Crystal 来自你刚才报告的现实回应”；
- `/reality` 只显示“带着新的呼吸继续走”，随后立即回到新 Pressure 候选；
- 用户无法从当前画面识别第一颗 Crystal 或身体留痕。

裁决：`Causal PASS / Experience OPEN`。

## 六、四类现实回应

本次远程正式路径重新完成 `改变回应`；其余三类使用同一不可变 Runtime SHA 已完成的正式 Push Gate / Closure 浏览器证据，并由远程 HEAD、Runtime SHA 与全量门禁重新核对。

| 现实回应 | Fact | Eligibility / Crystal | `/reality` | 惩罚 | 裁决 |
|---|---:|---|---|---|---|
| 已尝试 | `1` | 进入既有合法形成链 | 是 | 无 | PASS |
| 改变回应 | `1`，记录实际回应 | 进入既有合法形成链 | 是 | 无 | PASS |
| 尚未尝试 | `0` | `0` | 否 | 无 | PASS |
| 拒绝记录 | `0` | `0` | 否 | 无 | PASS |

尚未尝试或拒绝记录时：

- 不生成隐藏 Fact；
- 不生成 Eligibility 或 Crystal；
- 不进入伪造的新 Reality；
- 不惩罚、不倒计时、不损害星兽；
- Choice 与同行关系保持可恢复。

裁决：`PASS`。

Direct URL 不能凭 Identity、历史 Observation、Choice 或 Growth 资产绕过 Admission。

完整 Gate 重新确认旧周期、Identity、Choice、Route、Reality Proof 或 revision 失配进入 `SAFE_WITHHELD`，不产生伪成功。`mother-code-profile` 继续是独立基线黄灯，没有成为正式 Reality Adventure 消费者。

```text

↓

“你和它，带着新的呼吸继续走。”
“新的现实从远处靠近。”
↓

```

缺失的用户可观察桥梁：

```text
这次现实回应被同一生命接住
↓
Crystal 从这次回应形成
↓
Crystal 沉入同一身体
↓
用户看见具体 Body Imprint
↓

```

当前链条让技术系统知道 Growth 已形成，却让用户只感到“表单提交后又进入下一题”。

这不是视觉美化问题，而是产品因果没有被 Presentation 可靠表达；后续必须先冻结 Presentation State 和体验责任，再施工视觉。

## 十一、商业体验审查

### 第一轮免费价值

`PASS / 基础价值完整`：

- 用户获得一次具体 Pressure Recognition；
- 看见保护性回应；
- 得到可执行的现实微行动；
- 可以离开产品；
- 回来诚实记录尝试、改变、未尝试或拒绝；
- 事实与 Growth 资产可信保存。

第一轮不应在 Crystal 形成前设置付费墙。

### 第二次回访动机

`PARTIAL`：

- 同一 Identity、星兽、关系名和未完成 Choice 提供连续性；
- “我回来了”形成有辨识度的回访仪式；
- 但形成后的拥有感、身体变化与历史累积不可见，用户缺少“回来会看见生命如何改变”的明确期待。

### 长期价值来源

合法长期价值应来自：

```text
同一生命连续性
+
多次现实行动形成的可见身体变化
+
可恢复的 Growth 历史
```

不能来自一次性 AI 文案、无限候选或对话长度。当前 Runtime 已具备连续性底座，但 Presentation 尚未把该底座转化为用户可感知的长期价值。

### 订阅承载能力

`PARTIAL / 当前不宜启用`：

- 存在潜在持续价值；
- 但首次 Crystal、Body Imprint 与下一轮动机尚不可读；
- 此时引入订阅，用户更可能认为自己在为下一条文案或下一组问题付费，而不是为持续生命世界付费。

裁决：`Commercial Value Readiness = PARTIAL`。
