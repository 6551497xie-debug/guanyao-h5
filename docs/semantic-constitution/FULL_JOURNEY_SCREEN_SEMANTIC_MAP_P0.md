# XINMAI 1.0 全旅程逐屏语义地图 P0

每个节点均冻结 A 目的、B 参与理由、C 用户提供、D 系统使用、E 跳过/继续后果、F 允许隐喻、G 禁止误导、H 推荐界面语言。

## 1. Birth Coordinate

- A：建立肉身进入现实的时间坐标。
- B：为后续连续体验提供同一来源，不是预测人生。
- C：公历日期、当地时间/范围、精度和地点背景。
- D：既有 Birth Authority 推导文化时间表达与身份来源。
- E：信息不足则诚实扣留；确认后进入 Genesis；不伪造精确时间。
- F：时间坐标、星图起点。
- G：天命、性格判词、农历决定人生。
- H：标题“确认你的出生时间坐标”；说明“只用于建立这次体验的时间起点，不判断命运”；主操作“确认时间坐标”；次操作“暂时不知道精确时间”。

## 2. Genesis 形成与等待

- A：把已确认坐标转为可持续辨认的体验载体。
- B：建立进入 Reality 前的视觉连续性。
- C：无需新增资料，只等待或查看状态。
- D：消费既有 Genesis/Identity projection，不生成新结论。
- E：等待完成可继续；失败显示真实可重试性；无自动进入 Reality。
- F：星宿凝聚、星河亮起。
- G：宇宙正在揭示真实自我、动画完成即身份成立。
- H：标题“正在形成你的体验化身”；说明“它会陪你看见同一段旅程，不代表对你的定义”；主操作“继续”；次操作“稍后再来”。

## 3. 星宿化身 / 连续性说明

- A：说明化身是体验导航与跨轮视觉锚点。
- B：用户知道为什么它会持续出现。
- C：确认愿意以此载体继续，不要求相信客观生命存在。
- D：只读显示既有身份/视觉资产。
- E：确认进入可选 Whisper；暂不确认可退出，不损坏资产。
- F：生命化身、同行者。
- G：“认出它就是你”“同一个生命”作为继续条件。
- H：标题“这是陪你继续观察的化身”；说明“它帮助保持旅程连续，不是对你本质的判断”；主操作“继续体验”；次操作“先离开”。

## 4. Whisper

- A：给用户一个写给此刻自己的可选停顿。
- B：表达当下，不参与分析。
- C：可选短句或不写；原始文字 ephemeral。
- D：仅做当下视觉回应；不进入六维、Choice 或结果。
- E：“暂时不写”直接继续；提交失败可跳过；无惩罚。
- F：把一句话交给星光、留给此刻。
- G：系统读懂/分析耳语、耳语影响结果。
- H：标题“要不要写一句给此刻的自己？”；说明“只在此刻回应，不参与分析，也不会影响结果”；主操作“写下这句话”；次操作“暂时不写，继续”。

## 5. Naming（后移）

- A：第一轮价值闭环后，自愿建立个性化关系称呼。
- B：让持续使用更亲近，而非完成任务。
- C：可选称呼或保持默认。
- D：调用既有 Naming consumer/writer；不影响任何 lifecycle。
- E：跳过可直接开始下一 Reality；以后可在 Ownership 再设置。
- F：给同行者一个称呼。
- G：命名才获得生命、命名阻断 Reality、天地真名。
- H：标题“想给这位同行者一个称呼吗？”；说明“完全可选，不影响已经形成的记录或下一段现实”；主操作“保存称呼”；次操作“以后再说”。

## 6. Reality 入口与场景选择

- A：呈现当前 life stage 下可辨认的真实压力候选。
- B：找到真正触碰自己的现实，而非接受系统判断。
- C：选中一幕或继续看下一组。
- D：既有 Catalog/Bundle/Recognition Authority 记录候选引用。
- E：选中后进入六维；暂停不形成观察；新周期只读前置不同合格场景并标记刚完成场景。
- F：现实从远处显现、场景靠近。
- G：现实/宇宙选择用户、候选是命运结论。
- H：标题“此刻，哪一幕最像你正在面对的现实？”；说明“只选最接近的一幕，不需要选得准确”；主操作“就是这一幕”；次操作“看看其他现实”。

## 7. 六维总入口

- A：解释六个观察窗口和保存规则。
- B：让用户知道将看见反应链，而非做测验。
- C：选择开始或暂缓。
- D：建立/恢复 canonical observation set；进入不形成 OBSERVED。
- E：开始逐维；暂缓不补齐；恢复显示准确子集。
- F：从六个方向看同一幕。
- G：六项评分、人格雷达、完成即成长。
- H：标题“从六个角度看看反应是怎样出现的”；说明“每一步都由你确认；不强烈、不确定也可以”；主操作“开始观察”；次操作“暂时不做”。

## 8. BODY

- A：定位身体位置或节律。
- B：区分现实与最先出现的身体响应。
- C：LOCATED / UNLOCATED；PAUSED 不结算。
- D：最终确认时保存 bounded ID。
- E：保存后进入 EMOTION；暂停保留未完成状态。
- F：光沿身体位置移动。
- G：健康诊断、身体在告诉你真理。
- H：标题“身体”；问题“这件事发生时，身体哪里先有反应？”；主操作“保存身体观察”；次操作“先停一下”。

## 9. EMOTION

- A：辨认感受清晰度与混合状态。
- B：允许感受存在而不强迫命名。
- C：CLEAR / MIXED / UNCERTAIN。
- D：最终确认时保存 bounded ID。
- E：保存后进入 THOUGHT；不确定同样是合法观察。
- F：潮汐、颜色深浅。
- G：情绪诊断、好坏情绪排名。
- H：标题“情绪”；问题“此刻最靠近的感受，清楚到什么程度？”；主操作“保存情绪观察”；次操作“返回查看选择”。

## 10. THOUGHT

- A：识别最先出现的解释句或片段。
- B：看见想法如何塑造对现实的理解。
- C：SENTENCE / FRAGMENT / PRIVATE；原文不保存。
- D：只保存 semantic ID。
- E：保存后进入 ACTION；PRIVATE 不要求披露。
- F：短线、片段浮现。
- G：读心、补全用户想法、保存私密文本。
- H：标题“想法”；问题“脑中最先出现的是一句话、一个片段，还是你想保留的内容？”；主操作“保存想法观察”；次操作“内容暂时保留”。

## 11. ACTION

- A：识别第一行动冲动并与最终选择分开。
- B：找到可暂停和改变响应的位置。
- C：ADVANCE / WITHDRAW / PAUSE。
- D：保存 bounded ID；不宣称已经行动。
- E：保存后进入 MEMORY。
- F：方向向量、前后距离。
- G：冲动即行为、推进更勇敢、退开是失败。
- H：标题“行动冲动”；问题“你最先想推进、退开，还是停一下？”；主操作“保存行动观察”；次操作“重新选择”。

## 12. MEMORY

- A：区分过去熟悉感与当前事实。
- B：看见路径依赖但不要求披露经历。
- C：THEN / NOW / UNCERTAIN。
- D：保存 bounded ID，不保存记忆内容。
- E：保存后进入 GOAL。
- F：远近景深、旧光与当前光。
- G：创伤推断、前世、强迫回忆。
- H：标题“记忆联想”；问题“这更像过去熟悉的一幕，还是现在正在发生？”；主操作“保存记忆观察”；次操作“暂时分不清”。

## 13. GOAL

- A：识别反应试图保护的需要或方向。
- B：为微行动提供边界而非人格解释。
- C：NEED / VALUE / UNCERTAIN。
- D：保存 bounded ID；与 ACTION 一起供只读因果句使用。
- E：第六项确认后同事务形成 Receipt V2；不自动形成 Choice。
- F：核心光点、方向线。
- G：真实动机揭示、神圣使命、人格价值标签。
- H：标题“需要与方向”；问题“这份反应最不想失去的是什么？”；主操作“保存需要与方向观察”；次操作“暂时说不清”。

## 14. Response Map 与三层张力

- A：回看现实触发和六个准确选择，并提出可修正的三层问题。
- B：把六个碎片连成反应链。
- C：只阅读、返回修正未提交项；三层问题可选“不适用/不确定”。
- D：只读 Receipt V2/semantic selections；三层不持久化。
- E：确认理解后进入 Choice；证据不足则扣留具体因果推导。
- F：六条路径汇入同一场景。
- G：人格报告、根因诊断、三层主导评分。
- H：标题“刚才这段反应是怎样连起来的”；说明“这是你已确认的选择，不是对你的诊断”；主操作“带着这份理解继续”；次操作“返回查看”。

## 15. Choice

- A：形成最小、低风险、可撤销的行动假设。
- B：把 ACTION 冲动与 GOAL 需要转换为可验证的一小步。
- C：从既有合格 action routes 选一项并明确确认。
- D：Choice V4 绑定准确 Receipt/aggregate；不改行为 Authority。
- E：确认后等待 Departure；不确认不形成行动事实。
- F：从多条路径中点亮一条。
- G：仪式承诺、最佳答案、必须坚持。
- H：标题“下一次，先试一个足够小的不同回应”；说明“它可以撤销，回来后只看实际发生了什么”；主操作“带走这一步”；次操作“换一个更小的尝试”。

## 16. Departure

- A：明确从产品离开、回到真实生活。
- B：提醒行动尚未发生。
- C：明确离开。
- D：既有 Departure lineage；无 Fact/Crystal。
- E：离开后等待显式 Return；取消则留在当前页。
- F：从星河回到生活。
- G：启程即成长、系统会自动追踪现实。
- H：标题“把这一小步带回生活”；说明“真正发生以后，再回来告诉这里结果”；主操作“回到生活”；次操作“再看一次这一步”。

## 17. Return：真实回应选择

- A：回收实际发生的结果。
- B：让现实证据修正先前理解。
- C：ATTEMPTED / COMPLETED_AS_INTENDED / CHANGED_RESPONSE，或 no-fact 分支；可补一句事实。
- D：用户确认后既有 Fact Authority 才写入。
- E：合格事实进入 Formation；未尝试/拒绝记录均为零 Fact/Crystal。
- F：带回一段现实回声。
- G：自证成功、失败评价、系统推断结果。
- H：标题“现实里实际发生了什么？”；说明“只记录发生过的，不评价好坏”；主操作“确认这是实际发生的”；次操作“还没尝试 / 不想记录”。

## 18. NOT_ATTEMPTED

- A：合法结束当前回收且保留小行动。
- B：用户无需为未尝试制造结果。
- C：先回生活或返回重新选择。
- D：调用既有 no-fact typed reason；零 Fact/Crystal。
- E：主操作保留步骤并等待未来显式 Return；次操作回到上一选择面。
- F：暂时把一步留在路边。
- G：失败、落后、已经形成成长记录。
- H：标题“还没有在现实里试过，也没关系。”；说明必须交代保存位置与返回入口；主操作“先回到生活”；次操作“返回重新选择”。

## 19. USER_REJECTED_RECORD

- A：尊重用户不记录本次结果。
- B：避免被迫留下高信任记录。
- C：确认不记录或返回重新选择。
- D：既有 no-fact typed reason；零 Fact/Crystal。
- E：确认后回到生命世界；已有资产不变。
- F：把这次留白。
- G：惩罚、删除旧资产、暗示用户逃避。
- H：标题“不想留下这次记录，也可以。”；主操作“确认不记录，回到生命世界”；次操作“返回重新选择”。

## 20. Fact / Formation

- A：区分用户确认事实与后台合法形成过程。
- B：让用户知道保存依据是现实结果而非动画。
- C：Fact 内容已在 Return 提供，此屏不追加任务。
- D：既有 Fact/Eligibility/Formation Authority。
- E：pending 显示等待；retryable 才显示重试；non-retryable 安全退出。
- F：痕迹逐渐清晰。
- G：Fact/Receipt/Authority 等内部术语、形成动画等于成功。
- H：标题“正在保存这次现实结果”；说明“只有刚才确认的事实会进入记录”；主操作按 typed retryability；次操作“保留已确认内容并离开”。

## 21. Crystal / Ownership

- A：回看本轮从情境、反应、行动到结果的完整价值链。
- B：理解此次证据如何更新模型。
- C：可选轻触、可选 Naming、开始下一 Reality。
- D：只读 Formation/Crystal/Body/Response Map；Naming 使用既有可选 writer。
- E：Naming 跳过不阻断；下一 Reality 调用已接受 fresh-cycle controller。
- F：晶体、生命痕迹、同一星图中的位置。
- G：奖励、勋章、更好的人、轻触才生效。
- H：标题“这次现实留下了一道可回看的痕迹”；说明展示原情境、旧回应、小行动、实际结果、变化/延续、时间与序号；主操作“开始下一段现实”；次操作“可选：给同行者一个称呼”。

## 22. Archive

- A：跨轮回看用户确认过的事实和变化轨迹。
- B：比较不同情境下模型如何被现实修正。
- C：选择一条痕迹查看或开始新轮。
- D：只读 existing canonical projections；不生成汇总人格。
- E：查看不产生新资产；新轮创建 fresh Intent/Encounter。
- F：星图中的痕迹、时间轴。
- G：命运档案、人格报告、完成度等级。
- H：标题“你在现实中留下的观察记录”；说明“每一条都来自你确认过的现实结果”；主操作“查看这道痕迹”；次操作“开始下一段现实”。

## 23. Fresh Reality / 下一轮

- A：用新 Intent/Encounter 开始下一次现实实验。
- B：延续同一用户资产但不重复解释旧事实。
- C：选择新的合格场景。
- D：既有 repeated-cycle Authority；只读 history policy 前置另一合格场景并标记刚完成项。
- E：选择进入新六维 V3；返回 Archive 保留资产。
- F：星河展开下一段路径。
- G：旧 Intent 复用、邻近 stage fallback、重复场景冒充新周期。
- H：标题“下一段现实，从另一幕开始”；说明“上一段已保留，这里会建立新的观察”；主操作“选择这一幕”；次操作“回看已有痕迹”。
