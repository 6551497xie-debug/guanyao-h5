- 三论作为产品宪法与 copy lint 基线；
- 三层作为非持久化、可修正的解释问题；
- 六维 bounded semantic selections 与准确 Response Map；
- Reality → Choice → Departure → Return → Fact/Crystal → Archive 闭环；
- Birth 的非决定论文化时间说明；
- 化身作为连续体验载体；
- Whisper 完全可选、原文 ephemeral；
- Naming 后移为第一轮价值闭环后的可选关系动作；

- 390×844 / 320×568 可读与可操作；
- direct semantic gates、copy lint、Authority zero-drift gates。

- 自由文本语义分析；
- 人格画像、评分、雷达图、能力等级；

- Audio、Haptic、voice；

- 古代哲学—现代科学等价论证；
- 预测未来、命运或人格稳定特征。

- 用玄学隐喻替代任务说明；
- 用年龄、出生、星宿或一次反应定义用户；
- 未经用户确认保存自由文本或私密内容；
- 将未尝试、拒绝、跳过、动画完成伪造成 Fact/Crystal；
- 用页面本地状态冒充 canonical evidence；
- 新增第二 Catalog、第二 six-dimension Authority、第二 lifecycle owner；
- 当前 revision 重解释旧资产或 backfill exact selections。
