# 三论 × 三层 × 六维 × Reality 关系矩阵 P0

## 1. 四类对象不可混用

| 类别 | 回答的问题 | 数据地位 | 用户是否可修正 | 形成事实吗 |
|---|---|---|---|---|
| 三论 | 产品如何理解人、知识与行动 | 产品宪法 | 不是用户画像 | 否 |
| 三层 | 为什么可能产生张力 | Presentation hypothesis | 是，可说“不适用/不确定” | 否 |
| 六维 | 反应如何在当下出现 | Canonical bounded evidence | 通过逐维明确选择 | 是，限选择事实 |
| Reality loop | 行动假设在现实中发生了什么 | Canonical lifecycle/fact lineage | Return 时确认 | 是 |

## 2. 三论对产品节点的约束

| 节点 | 本体论约束 | 认识论约束 | 方法论约束 |
|---|---|---|---|
| Birth/Genesis | 坐标不是人格 | 文化表达不是命运证据 | 只建立体验入口 |
| Reality | 情境与人相互作用 | 候选不是系统真相 | 用户辨认真实压力 |
| 六维 | 反应是动态链 | 选择是有限观察 | 六项逐项确认 |
| 三层 | 没有高低本质 | 只是可核对假设 | 用问题帮助理解张力 |
| Choice | 用户可改变响应 | 不是最佳答案 | 形成最小验证行动 |
| Return | 结果不定义用户 | 事实可修正模型 | 回收尝试结果 |
| Crystal/Archive | 痕迹是过程资产 | 不总结命运 | 跨轮积累可回看证据 |

## 3. 三层与六维的合法关系

| 六维 | 本能系统可能关注 | 社会系统可能关注 | 超越系统可能关注 | 公开表达规则 |
|---|---|---|---|---|
| BODY | 安全、资源、身体边界 | 社会压力的身体负担 | 长期投入的身体代价 | 只问“身体出现什么”，不判层 |
| EMOTION | 警觉、舒适、失去 | 关系、归属、评价 | 公平、价值受损感 | 混合/不确定合法 |
| THOUGHT | 风险与资源判断 | 角色、规则、他人评价 | 真理、长期方向 | 不保存自由文字 |
| ACTION | 推进、退开、冻结 | 顺从、协商、代表边界 | 坚持、创造、修正系统 | 冲动不等于行动 |
| MEMORY | 旧安全策略 | 旧关系/角色模式 | 长期承诺与路径依赖 | 不要求披露过去 |
| GOAL | 需要与延续 | 关系、责任、意义 | 价值、公平、创造 | 不推断人格动机 |

任何单一六维选择都不能证明某一层。三层 Presenter 必须同时满足：有现有 source evidence、有“可能”措辞、有“不确定/不适用”出口、无持久化。

## 4. 三层与 Pressure 语义的只读线索

| 已有 source | 可提示的问题 | 不得推出 |
|---|---|---|
| RESOURCE / SURVIVAL / BODY evidence | “这里是否在保护基本资源、时间或身体边界？” | 用户处于生存危机 |
| ATTACHMENT / BELONGING / OBLIGATION / EVALUATION | “关系、群体、承诺或评价是否在施压？” | 人格依恋/社会能力结论 |
| CONTROL | “谁能决定、代表或改变边界？” | 用户控制欲强弱 |
| IDENTITY + GOAL VALUE/NEED | “角色连续性或长期价值是否被触碰？” | 超越系统主导、使命结论 |

pressureNature 仍是 Runtime candidate semantics；三层提示只是只读文案，不生成新分类或 hash。

## 5. Reality 反馈闭环的证据边界

| 顺序 | 用户动作 | Canonical evidence | Presentation 可说 | 不可说 |
|---|---|---|---|---|
| 1 | 选中情境 | Pressure recognition | “这是你认出的现实” | “宇宙选择了你” |
| 2 | 六维逐项确认 | Set/Items/Receipt | “你刚才选择了……” | “你就是……” |
| 3 | 阅读三层问题 | 无新增 evidence | “也许涉及……” | “根因是……” |
| 4 | 选择微行动 | Choice V4 | “准备尝试的一小步” | “改变已经发生” |
| 5 | 回到生活 | Departure/Return lineage | “等待真实结果” | “已完成成长” |
| 6 | 回来确认结果 | Fact or no-fact outcome | “你确认实际发生……” | 未尝试也算事实 |
| 7 | 合法形成 | Formation/Crystal/Body | “留下可回看的痕迹” | 奖励、升阶、命运结论 |
| 8 | 再开新轮 | fresh Intent/Encounter | “用新证据继续更新理解” | 用旧 Intent 重解释新现实 |

## 6. 公开术语表

| 内部术语 | 公开首选 | 允许次层解释 | 禁止公开替代 |
|---|---|---|---|
| ontology | 人是持续变化的系统 | 身体、经验、关系、环境、选择相互作用 | 固定本质 |
| epistemology | 当前理解可以被现实修正 | 有限模型/证据 | 绝对真相 |
| methodology | 观察—行动—反馈 | 小步验证 | 仪式完成 |
| instinct system | 身体与基本安全 | 资源/边界/延续 | 兽性 |
| social system | 关系、规则与责任 | 身份/归属/意义 | 人性等级 |
| transcendent system | 长期价值与方向 | 公平/创造/未来 | 神性 |
| Observation Receipt | 六个观察已保存 | 完成凭证只在 typed DOM | Receipt |
| Choice | 带回生活的一小步 | 可验证行动假设 | 命运选择 |
| Fact | 实际发生的事 | 用户确认事实 | Fact |
| Crystal | 生命痕迹/一次模型更新证据 | 可回看变化记录 | 奖励水晶/占卜结果 |
