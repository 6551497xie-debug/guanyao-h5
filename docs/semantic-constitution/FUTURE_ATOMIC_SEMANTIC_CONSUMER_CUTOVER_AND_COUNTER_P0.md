## 4. Direct-child Forward Counter

唯一策略：

`XINMAI_SEMANTIC_CONSTITUTION_EXPERIENCE_POLICY: ENABLED → SAFE_WITHHELD`

Counter 只暂停新语义 Presenter，显示一套完整、现代、静态、可访问的安全说明：当前目的、已有事实、真实可用操作。它必须：

- 保留所有 canonical Birth/Identity/Reality/Six-Dimension/Choice/Fact/Crystal/Body/Archive 资产只读恢复；
- 不恢复玄学操作逻辑、旧 Naming 假出口或“同一个生命”信念门槛；
- 不删除 Response Map 或三层说明，只将未能安全映射的具体解释扣留；
- 不改变 route、Admission、retryability 或 active lifecycle；
- 不新增 Store、fallback、Writer 或旧 Presenter；
- Candidate 的直接子提交且 runtime behavior diff 仅该策略一行。

## 5. 正式验收矩阵

- 首次用户不读哲学文档也能完成 Birth → Archive；
- 每屏能回答“为什么、提供什么、如何使用、跳过/继续后果”；
- 六维显示用户已选内容，不只显示 6/6；
- 三层解释明确是问题/假设且不持久化；
- ACTION + GOAL + Choice 因果句与 evidence 一致；
- 未尝试/拒绝记录零 Fact/Crystal；
- 合格现实回应单一 Fact/Formation/Crystal/Body lineage；
- Naming 首轮前不可阻断，Ownership 后可选；
- Archive 不出现人格/命运汇总；
- fresh Reality 新 Intent/Encounter，前置不同合格场景；
- refresh/back/forward/multitab 不重复资产；
- 390×844、320×568、Motion/Reduced Motion、keyboard/screen reader facts/actions 等价；
- runtime errors/warnings=0。

## 6. Stop conditions

出现任一项立即停止并申请 Authority/Product Contract re-audit：

- 三层需要写入 persisted record；
- Naming 后移要求改变 naming schema/writer；
- Response Map 缺少合法 semantic evidence；
- 需要修改 Choice behavior、Fact/Crystal writer 或 fresh-cycle Authority；
- 需要新增 DB version/Store/Index；
- 需要 AI 推断、自由文本 persistence 或 current-revision reinterpretation。
