# 现有语句处置清单 P0

本表是后续原子 Cutover 的 copy inventory，不在本刀修改 Runtime。

## 保留

| 现有语句 | 处置理由 |
|---|---|
| “还没有在现实里试过，也没关系。” | 合法 no-fact、无羞辱 |
| “先回到生活” / “返回重新选择” | 两个真实出口 |
| “不想留下这次记录，也可以。” | 尊重拒绝记录 |
| “开始下一段现实” | 与 fresh-cycle Authority 一致 |
| “可以留下一句实际发生的事实” | 明确事实而非评价 |
| “说不清也是此刻真实的情绪位置” | 容纳不确定 |
| “系统不会替你补成结论” | 认识论边界正确 |
| “内容仍由你保留” | 私密文字不持久化 |
| “刚刚完成过的一幕” | 可见新周期 provenance |

## 改写

| 现有语句/模式 | 问题 | 冻结方向 |
|---|---|---|
| “现实先靠近，生命再回应” | 现实被拟人化为外部力量 | “现实发生时，你可以看看自己的回应” |
| “哪一幕，刚刚碰到了你的生命？” | 氛围压过任务 | “此刻，哪一幕最像你正在面对的现实？” |
| “不需要选得准确，先停在让身体有一点回应的那一幕” | 身体被提前设为唯一判断 | “选最接近的一幕；不确定也可以继续看” |
| “生命起点 / 本命底座” | 容易被读成命定 | “出生时间坐标 / 体验起点” |
| “确认这组生命起点” | 本体声明过强 | “确认时间坐标” |
| “认出它 / 它正在等你认出” | 要求相信客观存在 | “愿意以这个化身继续体验” |
| “同一个生命仍在” | 作为状态说明可误成信念要求 | “你的已有记录仍在，同一段旅程可以继续” |
| “动机” | 容易人格化 | “需要与方向” |
| “思维” | 偏技术术语 | “想法” |
| “行动”维 | 与已发生行为混淆 | “行动冲动” |
| “记忆”维 | 容易要求披露 | “记忆联想” |
| “轻触 Crystal，确认……” | 触摸像形成条件 | “可以查看这道痕迹，也可以直接继续” |
| “重试形成结晶” | 内部过程公开 | “重新保存这次现实结果” |
| “生命世界”作为唯一出口 | 含义不明 | 主操作用“回到生活/返回记录/开始下一段现实” |

## 删除

| 语句/模式 | 删除原因 |
|---|---|
| 公开 Fact / Receipt / Authority / digest / Choice V4 | 内部实现术语 |
| “兽性 / 人性 / 神性”页面标签 | 道德/宗教层级风险 |
| “你是……人格/原力” | 固定人格与命定 |
| “宇宙替你选择/揭示” | 把隐喻当事实 Authority |
| “天地之名/本命真名”作为继续条件 | 本体与宗教事实暗示 |
| “完成六维就形成成长/结晶” | 违反事实形成边界 |
| “这一轮先到这里”作为主要且无后果说明的出口 | 不可理解、无明确去向 |
| Return/No-Fact 中“给它一个称呼/调整称呼” | 与当前任务无关、形成假出口 |

## 下沉为氛围

| 语句/意象 | 可保留位置 | 约束 |
|---|---|---|
| 星河、星宿、光、轨道 | 背景、过渡、次级 eyebrow | 不承担操作说明 |
| 生命化身、同行者 | 视觉连续性说明 | 不宣称客观生命实体 |
| 晶体/结晶 | 图形与资产名称 | 主文案必须解释为现实痕迹 |
| 靠近、呼吸、沉回身体 | 动效/氛围提示 | 不作为唯一按钮或 evidence |
| 同一生命 | 次层连续性隐喻 | 主层改为“你的已有记录/同一段旅程” |

## 公开 copy lint 规则

未来 Gate 必须扫描正式 Consumer，禁止公开文本出现：`Authority`、`Receipt`、`digest`、`Fact`、`Choice V3/V4`、`SAFE_WITHHELD`、`兽性`、`神性`、命定式“你就是/注定/必然”。Typed DOM data attribute、测试和开发日志不在公开 copy lint 范围。
