# XINMAI 1.0 — Participation screen constitution

Every formal screen must visibly contain, in this order:

1. **Where I am** — a short stage label.
2. **What is happening** — one concrete scene or fact.
3. **What I can do** — one primary decision, with real alternatives when alternatives exist.
4. **What changes next** — a concise consequence, shown only when needed.

The primary surface must not contain implementation explanations, evidence terminology, schema terminology, safety boilerplate or repeated disclaimers. Necessary safeguards belong in concise contextual help, error recovery or accessibility text.

## Journey promise

`带一个最近卡住你的现实问题进来。用一次小实验，看看现实会怎样回应。`

## Three-act six-dimensional language

- Act 1 · Signal: `先看反应，不急着解释。`
- Act 2 · Prediction: `看见脑中判断，以及它准备让你做什么。`
- Act 3 · Pattern and stake: `辨认熟悉感，以及这条反应试图保护什么。`

## Model-update language

- Before reality: `我的暂时判断`
- Chosen action: `这次要验证的小实验`
- After return: `现实给出的反馈`
- Final state: `下一次，我要保留 / 调整 / 继续观察`

Crystal remains the visual carrier of this update but never becomes the reason to participate.
