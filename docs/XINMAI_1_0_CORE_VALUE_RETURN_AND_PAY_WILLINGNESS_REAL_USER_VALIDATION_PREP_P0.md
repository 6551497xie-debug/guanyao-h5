## 一、唯一目标

冻结一套可执行、可复核、不会互相污染的真实用户纵向验证协议，分别证明：

```text
A. 用户是否真实感受到核心价值

B. 用户是否因为同一生命的连续性自然回来

C. 免费价值完整成立后，用户是否愿意为长期连续性付费
```

三层必须依次发生、分别记录、分别裁决。

本PREP不招募用户、不运行研究、不接支付、不创建等待名单、不测试价格，也不授权任何商业Runtime。

---

## 二、为什么必须拆成三层

以下三句话不是同一证据：

```text
“我喜欢这个概念。”
≠
“我会自己回来。”
≠
“我愿意为持续价值付费。”
```

如果在首次体验前介绍“生命资产”“同一生命记得你”或会员价值，用户后续复述很可能只是重复研究者提供的语言。

如果在Formation情绪高点立即询问付费，得到的更可能是即时好感、礼貌或沉没成本反应，而不是长期价值判断。

如果把满意度、回访和付费意愿合成一个总分，就无法定位问题属于：

- 核心价值没有被体验出来；
- 用户理解价值但没有自然复访动机；
- 用户愿意复访但不认为长期服务值得付费；
- 商业概念误导用户以为既有生命资产会被锁定。

因此本协议禁止使用“综合满意度”替代三层证据。

## 三、三层验证模型

## A｜Value Comprehension

### 3.1 要证明的命题

用户在没有被研究者告知答案的情况下，能够用自己的话表达：

> 我在现实中的一次行动或改变，被同一个生命记住，并留下了可辨认的变化。

### 3.2 必须区分的理解

正确理解至少包含：

- Crystal来自现实尝试或改变回应，不是点击奖励；
- “尝试过”而非“成功了”足以形成真实经历；
- Body Imprint属于同一星兽身体，不是新皮肤或第二只星兽；
- 系统在记录并呈现用户事实，不是在评定用户更好、更勇敢或更高级。

错误理解包括：

- 星座、算命或命运预测；
- AI生成了一份人格报告；
- 完成任务获得宝石奖励；
- 收集更多Crystal就会升级；
- 星兽因为用户表现好而进化；
- 用户必须成功完成行动才能被认可。

### 3.3 无提示开放问题

Formation与Returning体验完成后，首先只问：

1. 刚才发生了什么？
2. 为什么出现这颗Crystal？
3. 星兽哪里发生了变化？
4. 你觉得这个变化和你在现实中做的事情有什么关系？
5. 如果你没有成功做到原计划，但真实尝试过，会发生什么？
6. 这只星兽和你第一次看见的是同一个吗？为什么？

在用户回答完成前，研究者不得说出：

- 生命资产；
- 它记住了你；
- 同体留痕；
- 真实行动形成Crystal；
- 长期连续性。

### 3.4 A层裁决

| 结果 | 条件 |
|---|---|
| `PASS` | 用户无提示复述“现实回应 → 同一生命留下变化”，且不依赖奖励/命运框架 |
| `PARTIAL` | 用户认出行动与Crystal有关，但不能确认同一生命或把尝试误解成成功 |
| `FAIL` | 用户主要记住特效、奖励、星座、算命、AI答案或任务完成 |

---

## B｜Return Motivation

### 3.5 要证明的命题

用户再次进入不是为了领取新内容、获得安慰或查看随机变化，而是因为：

> 我想看看同一个生命现在怎样，以及它是否仍记得我经历过的事情。

### 3.6 自然回访定义

强证据只来自：

- 用户在约定窗口内未经产品提醒主动打开；
- 用户主动找到Returning入口；
- 用户能说明回来时想确认或继续什么；
- 即使没有新文案、奖励或视觉惊喜，仍认为回来有意义。

研究运营提醒必须与产品回访严格分开：

- 研究开始前可以说明回访窗口；
- 窗口内不发送产品式召回；
- 如为安排访谈不得不发送中性提醒，该用户记录为`RESEARCHER_PROMPTED_RETURN`；
- 被提醒后回来不能计入“未经提醒主动回来”的强证据。

### 3.7 回访后开放问题

1. 你什么时候第一次想到要回来？
2. 当时是什么让你想到这里？
3. 如果回来后没有新内容，只看到同一个生命仍在，你还会觉得值得吗？
4. 你想确认的是自己、Crystal、星兽，还是下一段新内容？
5. 如果产品一周都不提醒你，你觉得自己还会在什么时刻回来？
6. 什么会让你不想再回来？

### 3.8 B层回访分类

```text
SPONTANEOUS_CONTINUITY_RETURN
用户未经提醒回来，动机指向同一生命与持续记忆

SPONTANEOUS_OTHER_RETURN
用户未经提醒回来，但主要为了新内容、安慰或视觉新鲜感

RESEARCHER_PROMPTED_RETURN
研究提醒后回来

NO_RETURN
窗口内未回来
```

### 3.9 B层裁决

| 结果 | 条件 |
|---|---|
| `PASS` | 出现可重复的`SPONTANEOUS_CONTINUITY_RETURN`，用户不依赖新内容也认可回访 |
| `PARTIAL` | 用户会回来，但主要依赖提醒、安慰、AI新内容或视觉新鲜感 |
| `FAIL` | 用户没有自然回来理由，或认为首次体验已经完成且无需再次进入 |

## C｜Pay Willingness

### 3.10 要证明的命题

只有A、B层证据已经记录后，才验证：

> 用户是否愿意为更长期的生命连续性、历史回看和主动深度照见付费，而不是误以为付费才能保存Crystal或继续拥有星兽。

### 3.11 商业概念展示前置

必须同时满足：

- 用户已经完成免费首次成长闭环；
- 用户已经离开产品并在后续窗口回访；
- A与B的开放问题已经完成；
- 当前位于中性、平静、可退出的研究环节；
- 没有活动中的Pressure、Gravity、Choice、Return、Formation或恢复失败；
- 研究者明确说明既有Identity、Crystal、Body Imprint与基础历史不会因不付费而消失。

### 3.12 只允许测试的四类价值

| 概念 | 中性描述 | 不得暗示 |
|---|---|---|
| 长期连续记录 | 让同一生命在更长时间里连接多次现实经历 | 更多Crystal、更快成长 |
| 完整历史回看 | 看见不同经历如何在同一身体与时间中累积 | 不付费就失去历史 |
| 主动深度照见 | 用户主动请求更长时间范围的整理、提问与连接 | 更准确命运或人格结论 |
| 可选表达丰富度 | 更丰富的声音、材质与生命空间表现 | 付费结果更高级、无障碍版本次等 |

### 3.13 标准化免费基线卡

展示任何会员概念时，必须同时展示免费基线：

```text
无论是否加入长期同行：

你的Identity、同一星兽、已经形成的Crystal、
Body Imprint与基础历史仍属于你并保持可访问。
```

免费基线不是脚注，必须与会员概念同等可见。

### 3.14 概念测试问题顺序

1. 在这些能力中，哪些对你有持续价值？为什么？
2. 哪些你认为必须永久免费？
3. 如果只能保留一个付费能力，你会保留哪一个？
4. 哪个能力让你觉得是在为连续生命世界付费？
5. 哪个能力让你觉得只是在购买更多内容？
6. 如果停止付费，你认为哪些东西仍应属于你？
7. 你是否愿意在未来收到该服务可用的通知？
8. 你是否愿意主动留下非交易购买意向或进入等待名单？

本阶段禁止把“你愿意付多少钱？”作为单独的成立证据。价格研究继续`DEFER`。

### 3.15 C层裁决

| 结果 | 条件 |
|---|---|
| `PASS CANDIDATE` | 用户在完整免费价值后主动选择长期连续性能力，并正确理解既有资产不被锁定 |
| `PARTIAL` | 用户愿意继续使用，但只认可AI内容、视觉特效或一次性历史报告 |
| `FAIL` | 用户没有可付费持续价值，或误以为必须付费才能保住Crystal、星兽或成长资格 |

## 四、P0真实体验研究结构

### 4.1 样本规模

建议：`8–12名`真实目标用户。

此规模用于发现价值理解与行为模式，不用于宣称统计显著或市场规模。

### 4.2 样本构成

建议覆盖：

- 正在经历普通现实压力、但不处于急性危机的目标用户；
- 对自我观察、成长、东方文化或生命陪伴有不同熟悉度的用户；
- 既有AI陪伴/心理内容使用者与非使用者；
- 至少两种正式设备条件；
- Motion、Reduced Motion与无障碍需求在发布范围内有代表性覆盖。

不得为提高好评只招募：

- 项目成员或已读过产品协议的人；
- 东方哲学重度爱好者；
- 已被告知产品核心主张的人；
- 只因视觉审美匹配而入选的人。

### 4.3 招募伦理

未来招募必须：

- 明确这是产品研究，不是治疗、诊断或命运咨询；
- 不以严重痛苦、危机或创伤作为入组激励；
- 研究补偿与好评、完成行动、回访及购买意向无关；
- 用户可随时退出且保留约定补偿；
- 不要求披露超出体验所需的敏感细节；
- 录音、录像、引用与等待名单分别取得同意。

本PREP不授权实际招募。

## 五、纵向时间线

### 5.1 Day 0｜首次成长与明确离场

用户通过正式产品路径完成：

```text
Identity
→ Relationship
→ Reality Pressure Recognition
→ Gravity Observation
→ Action Route Choice
→ Explicit Departure
```

观察并记录：

- 用户是否理解行动路线；
- 用户是否知道现在应离开产品；
- 用户是否把Choice误解为完成任务；
- 用户是否愿意在现实中尝试，而非为了研究者完成动作。

Day 0不解释Crystal、Body Imprint、长期连续性或会员。

### 5.2 Day 1–3｜现实决定窗口

用户自行决定：

- 尝试；
- 改变回应；
- 尚未尝试；
- 拒绝记录。

研究者不得：

- 催促行动；
- 暗示行动成功会获得Crystal；
- 用补偿与完成动作挂钩；
- 通过提醒制造产品回访；
- 把未行动解释为研究失败。

### 5.3 Return｜自主回访

记录：

- 是否未经提醒回来；
- 从哪里进入；
- 是否自然找到“我回来了”；
- 返回前的真实动机；
- 是否能区分尝试、成功、改变回应和拒绝记录。

### 5.4 After Formation｜拥有与同体记忆

仅对正式形成路径记录：

- Crystal行动归因；
- “尝试而非成功”理解；
- Ownership感；
- Same-Life Body Imprint识别；
- 用户是否产生下一次自然回访理由。

尚未尝试或拒绝记录的用户不得为了研究完整性被迫进入Formation。

### 5.5 Neutral Surface｜会员概念

在A、B证据完成后，进入独立中性环节：

- 先重申免费基线；
- 展示四类持续价值概念；
- 不展示价格、折扣、倒计时或试用；
- 不模拟锁定资产；
- 不要求现场购买；
- 只记录选择、理由、顾虑与非交易意向。

## 六、主持纪律与污染控制

### 6.1 研究者禁止语

开放回答完成前禁止：

- “它记住了你”；
- “这是你的生命资产”；
- “同一生命连续性”；
- “你的真实行动形成了Crystal”；
- “这是长期陪伴”；
- “很多用户会愿意付费”；
- “你觉得这个功能值多少钱”。

### 6.2 允许追问方式

允许：

- “你为什么这样理解？”
- “你在画面或流程的哪里感受到这一点？”
- “如果没有这部分，会有什么不同？”
- “你刚才提到‘奖励’，它对你意味着什么？”
- “你说会回来，是什么时刻让你想到回来？”

禁止：

- 纠正用户答案；
- 用协议语言重述并要求确认；
- 暗示存在正确理解；
- 把礼貌性认可记为付费意愿；
- 在沉默时主动解释产品哲学。

### 6.3 刺激物控制

所有参与者使用同一版本：

- 正式生产路径；
- 同一会员概念卡；
- 同一免费基线卡；
- 同一问题顺序；
- 同一研究窗口规则。

禁止使用Fixture、Acceptance Page、手工Storage或研究者代操作制造成长资产。

## 七、证据分级

| 等级 | 证据 | 可证明 | 不能证明 |
|---|---|---|---|
| E1 弱 | 用户说喜欢、好看、有意思 | 即时好感 | 核心价值、复访、付费 |
| E2 中 | 用户无提示准确复述核心因果 | Value Comprehension | 自然复访、商业价值 |
| E3 强 | 用户未经提醒主动回来，并说明连续性动机 | Return Motivation | 付费意愿 |
| E4 商业强 | 免费闭环后主动选择长期连续性能力 | Pay Willingness Candidate | 真实交易与续费 |
| E5 最高非交易 | 用户自愿留下真实购买意向或进入等待名单 | 非交易需求信号 | 定价、付款、长期留存 |

以下不得升级为E4或E5：

- “如果便宜我可能会买”；
- 主持人点名某能力后用户同意；
- Formation高潮后的即时好评；
- 为获得研究补偿选择等待名单；
- 认为不付费会丢失Crystal而产生的意向。


任何时候研究者提供了核心产品词，都必须记录：

```text
UNAIDED
LIGHTLY_PROBED
RESEARCHER_PROMPTED
CONTAMINATED
```

只有`UNAIDED`可以作为A层通过的主要证据。

## 九、P0决策阈值

小样本阈值只用于决定下一步，不代表市场规模或统计显著。

### 9.1 A层阈值

- ≥80%参与者无提示复述“现实回应 → 同一生命留下变化”；
- ≥75%区分“尝试”与“成功”；
- ≥75%认出Returning是同一星兽；
- ≤20%主要理解为奖励、星座、算命、AI报告或任务升级。

### 9.2 B层阈值

- ≥50%在研究窗口内未经产品提醒主动回来；
- 在主动回来者中，≥70%将动机指向同一生命、持续记忆或继续观察；
- ≤20%只因新内容、安慰或视觉新鲜感回来；
- 研究提醒后回访必须单独报告，不能填补自然回访缺口。

### 9.3 C层阈值

- ≥40%在完整免费闭环后主动选择至少一项长期连续性能力；
- ≥70%能正确解释付费对象是持续服务，而非Crystal、命运或成长资格；
- ≥25%自愿留下真实购买意向或等待名单同意；
- 0名参与者认为停止付费会失去既有Identity、Crystal或Body Imprint；
- 0次在禁止时点展示商业概念。

阈值不达成时不得加强营销、提醒或稀缺话术。

## 十、失败出口

### 10.1 A失败｜返回Phase 3体验语义

如果用户主要记住：

- 星座或算命；
- 情绪安慰；
- 漂亮特效；
- 收集Crystal；
- 完成任务获得奖励；

则裁决：

```text
CORE VALUE NOT FELT
→ Phase 3 Experience Semantic Correction
→ 禁止进入付费验证
```

不能用品牌故事、主持人解释或营销文案补救。

### 10.2 A通过、B失败｜持续价值不足

用户理解首次体验，但没有自然回来理由：

```text
ONE-TIME VALUE ESTABLISHED
CONTINUITY VALUE OPEN
→ Return Motivation Product MAP
```

不得用Push、红点、签到或星兽衰败制造回访。

### 10.3 A/B通过、C失败｜商业价值未成立

用户会回来，但不愿为当前持续能力付费：

```text
PRODUCT RETENTION VALUE ESTABLISHED
MONETIZABLE VALUE OPEN
→ Commercial Capability Reframing MAP
```

产品可以继续以免费或其他模式存在，不能因为商业失败否定生命价值。

### 10.4 出现资产被锁误解｜伦理红灯

任何参与者认为：

- 不付费会失去Crystal；
- 不付费星兽会衰败；
- 付费才有资格继续成长；
- 付费能得到更好的命运；

则相关刺激物立即停止，裁决：

```text
RED — ETHICAL OFFER FAILURE
```
